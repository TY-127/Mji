# AI 小手机 (AI Virtual Phone) - 系统架构设计文档

## 1. 系统概述
本项目旨在 Android 平台上构建一个完全由 AI Native 驱动的虚拟智能手机系统（SillyTavern 衍生概念）。系统提供沉浸式的角色扮演、社交陪伴与互动体验，采用端云结合的架构。

## 2. 核心技术栈
* **前端 UI**: Kotlin (原生 Android 开发，提供极致流畅的仿系统级交互)
* **核心逻辑层**: C++ (通过 JNI/NDK 与 Kotlin 通信，负责高性能的上下文与记忆计算)
* **持久化存储**: SQLite (轻量级本地关系型数据库)
* **大语言模型 (LLM)**: 通过网络 API 调用外部云端大模型 (RESTful/WebSocket)

## 3. 模块职责划分

### 3.1 表现与网络层 (Kotlin)
* **UI 渲染**: 负责绘制仿 iOS/Android 的桌面、应用图标、状态栏以及各类虚拟 App 的界面。
* **输入捕获**: 处理用户的屏幕触控、滑动、键盘输入及麦克风语音输入。
* **网络通信**: 承载与 LLM 云端的 HTTP/WebSocket 通信。虽然 C++ 也能做网络请求（如 libcurl），但在 Android 环境下，使用 Kotlin 结合 OkHttp/Retrofit 处理网络请求和 SSL 证书会更加稳定且契合生态。
* **JNI 桥接**: 负责将用户的操作指令和网络返回的数据透传给 C++ 核心引擎。

### 3.2 核心大脑层 (C++ NDK)
* **Prompt 组装工程**: 这是 C++ 层的核心。负责将当前用户输入、历史聊天记录、当前虚拟系统的状态、以及环境变量融合。
* **世界书 (World Info) 引擎**: 基于关键词或向量空间（可选）实现高效的 Lorebook 词条匹配和拉取。
* **记忆系统管理**: 管理角色的长期记忆（提炼后的 Summary）和短期记忆（最近对话上下文窗口滑动），并计算 Token 消耗以防止溢出。
* **事件状态机**: 维护虚拟世界的时间线、好感度系统或随机触发事件的判定。

### 3.3 数据存储层 (SQLite)
* **User/Bot 预设库**: 存储各个人设的性格描述、开场白、头像路径等。
* **世界书数据**: 存储触发词与对应的内容设定。
* **对话与记忆流**: 存储结构化的聊天记录（JSON 格式或分表存储）。
* **虚拟系统状态**: 保存当前的“系统时间”、未读消息数、虚拟应用状态等。

## 4. 核心数据流转 (Data Flow)
1. **用户操作**: 用户在 Kotlin UI 中发送一条“微信”消息。
2. **下沉**: Kotlin 通过 JNI 将 `[时间, 发送者, 消息内容]` 传递给 C++。
3. **计算**: C++ 从 SQLite 提取对话上下文、查询世界书、拼装成最终的 `System Prompt + User Prompt`。
4. **上浮**: C++ 将拼装好的字符串通过 JNI 返回给 Kotlin。
5. **请求**: Kotlin 网络层向 LLM API 发起请求，获取流式 (Stream) 或完整响应。
6. **回写与渲染**: Kotlin 将收到的 AI 回复显示在 UI 上，同时通过 JNI 通知 C++ 解析状态并持久化写入 SQLite。
