# AI 小手机 - 虚拟应用功能规格说明书 (V1.0)

## 1. 社交互动类
### 1.1 朋友圈 (Moments)
* **功能**: AI 角色会根据世界书设定或当前剧情发布动态（图文）。
* **交互**: 用户可以点赞、评论。AI 会根据逻辑层（C++）的判定在评论区回复用户。
* **AI 驱动**: 当满足特定时间或事件（如好感度突破）时，由 C++ 逻辑层触发动态生成任务。

### 1.2 虚拟论坛 (Virtual Forum)
* **功能**: 模拟一个多人互动的环境（如类似 Reddit 或贴吧）。
* **作用**: 用于展示更宏大的世界观，用户可以观察不同 AI 预设之间的互动。

## 2. 经济与情感价值类
### 2.1 转账与红包 (Finance)
* **功能**: 模拟资金往来。
* **影响**: 用户向 AI 发红包或转账可快速提升好感度，或解锁特定剧情对话。

### 2.2 礼物系统 (Gift Shop)
* **功能**: 用户购买虚拟商品送给 AI。
* **持久化**: SQLite 记录 AI 收到的礼物清单，C++ 逻辑层将其作为上下文的一部分（例如 AI 会提到：“谢谢你昨天送我的项链”）。

## 3. 生活服务类
### 3.1 外卖 (Food Delivery)
* **功能**: 纯模拟交互。用户下单后，AI 会有相关的反馈（如“一起吃吧”或者“谢谢你点的奶茶”）。
* **状态机**: 包含：下单 -> 配送中 -> 已送达 的状态切换，由系统时间驱动。

### 3.2 天气 (Weather)
* **功能**: 同步真实天气或根据虚拟世界设定生成天气。
* **关联**: 天气数据将作为全局 Context 输入给 AI（如：下雨天 AI 的语气可能更忧郁或温馨）。

## 4. 工具与计划类
### 4.1 日历与备忘录 (Calendar/Memo)
* **功能**: 记录重要日子。
* **主动触发**: C++ 逻辑层轮询 SQLite 中的提醒事项，通过系统通知或“即时通讯 App”让 AI 主动开启话题。
